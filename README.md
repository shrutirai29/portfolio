# Shruti Rai — Cinematic Portfolio

An editorial, cinematic portfolio engineering experience that **scrolls like a film** — natural flowing sections with signature camera moments, fluid magnetic cursor interactions, and responsive design.

The experience opens directly with **SHRUTI RAI** and the signature pinned camera move — a **whole-screen zoom into the "A"** — before settling into a premium editorial journey through About, Tech Stack, Projects, Journey & Credentials, Fun Facts, and Contact.

## ✨ Key Features & Enhancements

- 🛸 **Floating Glass Dock Navigation** — Glassmorphic top dock with real-time active section tracking, direct navigation links, and mobile-friendly drawer menu.
- 🎯 **Fluid Magnetic Custom Cursor** — Smooth lerp follower ring that expands on interactive elements, accompanied by an ambient mouse-following spotlight glow.
- 🔊 **Procedural Web Audio Micro-Interactions** — Synthesized Web Audio API sound effects (hover chimes and ambient atmospheric drone), zero external heavy audio files, muted by default with an interactive header toggle.
- 📄 **Integrated Resume / CV** — One-click view & download for Shruti's verified résumé (`resume.pdf`) across header, about, case studies, and contact hub.
- 🎓 **Journey & Milestones Section** — Dedicated credentials spotlighting Infosys Springboard internship, Rashtriya Raksha University academics (CGPA 8.17), TryHackMe Global Top 5%, and LeetCode problem solving.
- 🗂️ **Filterable Project Showcase** — Interactive category filters (`All`, `AI & ML`, `Full-Stack`, `Systems & Tools`, `Creative & WebGL`) with direct Live Demo pills and GitHub repository shortcuts.
- ⌨️ **Keyboard-Driven Project Case Studies** — Detailed project pages (`#/project/01` …) with `Esc` to return to journey, and `←` / `→` arrow keys for seamless browsing.
- 📋 **Interactive Contact Hub** — One-click clipboard copy for primary email (`24bcscs047@student.rru.ac.in`) and phone (`+91 7007787536`) with instant visual feedback.

## 🛠️ Tech Stack

- **React 18 + Vite** — High-performance SPA with hash routing
- **GSAP 3 + ScrollTrigger** — Scroll-driven timeline choreography and section reveals (Lenis-synced)
- **Lenis** — Smooth inertial scrolling
- **Web Audio API** — Procedurally synthesized micro-interactions
- **Typography** — Playfair Display (display serif) × Manrope (body) via Google Fonts
- **Styling** — Custom CSS with glassmorphic cards, glow filters, and responsive layout

## 🚀 Running Locally
